---

把当前 Claude Code 会话导出为 ThoughtDAG 可导入的快照。规则与步骤：

1. **定位会话文件**：当前项目的会话 JSONL 存放在 `~/.claude/projects/<项目路径 slug>/` 下（slug = 项目绝对路径把 `/` 和 `.` 替换为 `-`）。用 `ls -t` 找该目录里**最近修改**的 `.jsonl` 文件——正在写入的那个就是当前会话。若参数 `$ARGUMENTS` 是 `list`，改为列出最近 5 个会话文件（文件名、大小、修改时间）让用户挑选，然后停下等待选择；若参数是某个会话 id 前缀，则选中匹配的那个文件。

2. **只读快照**：把选中的 JSONL **复制**一份到 `~/Desktop/thoughtdag-session-$(date +%Y%m%d-%H%M).jsonl`。绝不修改、移动或删除源文件——源会话只读是铁律。正在写入的文件可以安全复制（导入器逐行解析，容忍尾部截断行）。

3. **告知用户**（导出完成后）：
   - 快照文件的完整路径；
   - 打开方式：在 ThoughtDAG 中点左上角**画布切换器 → 导入**，选择这个文件（或把文件直接拖到导入对话框）。会话会以只读投影落成画布：每轮问答一个节点、工具调用成可单独排除的附件、compaction 边界显式标注、默认导入最近 200 轮；
   - 提醒：导入后即可在画布上检查上下文结构、剪除污染的轮次或工具输出。

4. 不要打印会话内容本身，不要解析或总结它——那是 ThoughtDAG 的工作。
