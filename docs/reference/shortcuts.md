# Keyboard shortcuts

| Action | macOS | Windows / Linux |
|---|---|---|
| Undo | `Cmd+Z` | `Ctrl+Z` |
| Redo | `Cmd+Shift+Z` | `Ctrl+Shift+Z` |
| Search the canvas | `Cmd+F` | `Ctrl+F` |
| Collapse or expand selected node | `Space` | `Space` |
| Regenerate selected node | `R` | `R` |
| Move through connected nodes | Arrow keys | Arrow keys |
| Step out of the current layer | `Esc` | `Esc` |
| Delete selected wires or a multi-node selection | `Delete` / `Backspace` | `Delete` / `Backspace` |

Arrow keys follow structural wires only. Deletion applies to selected wires or a selection of more than one node; deleting a single node uses its node action. When a text field is active, normal text-editing behavior takes priority.
