# 常见问题

## 应用打开了，但没有可用模型

打开**连接模型**，添加服务商、本地 Ollama 或自定义 OpenAI-compatible endpoint。确认接口能够返回模型列表，或者在界面允许时手动填写模型名称。

## 请求失败

检查错误提示、endpoint 地址、所选模型与凭证。失败节点可以重试；错误信息不会写入回答正文。

## PDF 无法选择文字

文件可能是扫描件。使用提取文本回退或识别功能，并在依赖生成文字前人工检查。

## 下游回答被标记为陈旧

上游节点、连线或当前版本发生了变化。先检查上下文差异，再只重放仍有价值的节点。

## Agent 对话地图中找不到本地 Agent 会话

Agent 对话地图是桌面/本地功能。确认受支持 runner 的本地 session 文件存在，并在 **Agent 对话地图 → 接入** 中启用来源。

## Windows 显示安全警告

当前 Windows 构建暂未签名。请只从官网或 GitHub Releases 下载，并确认文件来自项目正式发布页。
