# 功能导航

第一次使用？先看[认识界面](/zh/guides/interface-overview)。如果已经知道自己要完成什么，可以直接进入下面对应的功能页。每项功能只在一个页面完整说明，其他页面通过链接引用。

## 画布与节点

| 页面 | 说明 |
|---|---|
| [画布、导航与分区](/zh/guides/canvas-projects) | 浏览画布、切换阅读距离、整理布局和使用分区框 |
| [对话节点与侧栏](/zh/guides/conversations) | 阅读节点、打开完整侧栏，并完成编辑、分支、重算和右键操作 |
| [控制上下文](/zh/guides/context-control) | 查看和改变下一次请求真正包含的内容 |
| [材料节点与阅读器](/zh/guides/materials) | 导入来源，在阅读器中提问，并摘取可追溯的文字或图像证据 |
| [合并、高亮与凝练](/zh/guides/organize) | 合并节点、串联高光并生成可追溯的凝练副本 |
| [版本、陈旧与重放](/zh/guides/versions-replay) | 比较回答版本，并在上游变化后更新下游 |

## 工具与数据

| 页面 | 说明 |
|---|---|
| [模型、工具与记忆](/zh/guides/models-tools) | 连接模型，启用搜索或 MCP，并管理角色与环境记忆 |
| [Why 层：CLI 与 MCP](/zh/guides/why-layer) | 安装本地查询层，使用命令，并接入只读 MCP 工具 |
| [Agent 对话地图](/zh/guides/session-atlas) | 把本地 Agent 会话作为持续更新、可独立整理的图镜像打开 |
| [数据、备份与分享](/zh/guides/data-sharing) | 备份、导入、导出和分享画布 |

需要理解连线与模型输入之间的关系时，阅读[上下文图如何工作](/zh/concepts/)。
