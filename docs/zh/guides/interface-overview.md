## 1. 顶部工具栏

左上角的画布入口用于切换项目并进入 [**Agent 对话地图**](/zh/guides/session-atlas)。右上角工具栏会根据当前画布显示：

- [**模型选择器**](/zh/guides/models-tools#连接并选择模型)：切换默认模型，并进入模型与能力配置；
- [**重放陈旧节点**](/zh/guides/versions-replay#重放下游工作)：仅在存在陈旧节点时出现；
- [**分区导航**](/zh/guides/canvas-projects#使用分区框)：仅在画布包含分区框时出现；
- [**搜索节点**](/zh/guides/canvas-projects#找到节点)、语言切换、[**本地自动备份**](/zh/guides/data-sharing#自动文件夹备份)；
- [**更多操作**](#更多操作-菜单)、[撤销与重做](/zh/guides/data-sharing#恢复修改)。

### “更多操作”菜单

右上角的 **⋯** 集中放置低频的整张画布操作：

| 菜单项 | 作用 |
|---|---|
| [**显示 / 隐藏批注**](/zh/guides/canvas-projects#使用分区框) | 临时显示或隐藏分区框和未连线材料，只改变画面，不删除内容，也不改变模型上下文。 |
| [**一键排版**](/zh/guides/canvas-projects#整理布局) | 按连线方向重新整理节点位置；执行前会确认，只改变布局。 |
| [**全部高光**](/zh/guides/organize#高亮并串联) | 汇总整张画布的高光，可定位原节点、勾选串联或导出 Markdown；仅在已有高光时出现。 |
| [**全部材料**](/zh/guides/materials#其他材料操作) | 集中查看画布中的文件、图片、链接等材料，并返回它们在画布中的位置；仅在已有材料时出现。 |
| [**凝练**](/zh/guides/organize#凝练一条路径) | 检查适合降低颗粒度的连续对话，并在原图右侧生成凝练副本；原图保持不变。 |
| [**诊断画布**](/zh/features#整理与评审) | 检查残差边、影子引用、盲评破盲和过长链路等结构问题，给出报告但不自动修改。 |
| [**分享只读链接**](/zh/guides/data-sharing#分享只读图) | 先检查可能的敏感内容，再生成只读查看链接；接收者可以浏览，但不能修改原画布。 |
| [**导出备份 (.json)**](/zh/guides/data-sharing#导入与导出) | 把当前项目的节点、连线和内容导出为本地 JSON，用于备份、迁移或恢复。 |
| [**导出事件日志 (.csv)**](/zh/guides/data-sharing#导入与导出) | 导出带时间戳的提问、生成、高光和归档等操作记录；有事件记录时才出现。 |
| **光线** | 选择亮色、暗色或跟随系统。 |
| **纸质** | 切换纸面或网格；网格模式同时启用节点吸附。 |
| [**记忆**](/zh/guides/models-tools#管理环境记忆) | 查看、编辑、导入或导出跨画布的环境记忆。记忆开启时，已接纳的条目会进入普通生成的系统层。 |
| [**如何使用**](/zh/) | 打开应用内置的十步交互教程和快捷键提示。 |

菜单会根据当前画布状态省略不适用的入口，因此你的菜单可能比截图更短。

## 2. 画布

画布是主要工作区。按住鼠标中键或右键拖动可以平移，滚轮或双指滚动可以缩放；左键拖动空白处用于框选，双击空白处新建问题，拖动节点调整位置。框选两个以上节点后，顶部会出现[多选工具栏](/zh/guides/canvas-projects#多选工具栏)。画布底部还有缩放控件，右下角小地图也可以平移和缩放。完整操作见[画布、导航与分区](/zh/guides/canvas-projects)。

## 3. 节点

画布上有三类主要节点：

| 类型 | 保存什么 | 如何建立与打开 |
| --- | --- | --- |
| **问答节点** | 一次提问及其回答版本 | 提问或沿现有回答继续；双击节点打开[浮动侧栏](/zh/guides/conversations#浮动侧栏的功能区) |
| **便签节点** | 可直接编辑的文字或 Markdown | 新建便签，或把普通文字粘贴到画布 |
| **材料节点** | PDF、图片、Word `.docx`、HTML、Markdown、纯文本与常见代码文件，以及网页快照 | 拖入或粘贴文件；把单独的网页 URL 粘贴到画布会保存抓取时间与当时的页面内容；双击进入[材料阅读器](/zh/guides/materials#认识阅读器) |

问答节点保存一轮问题和回答。**双击问题**可以修改问题；回答使用末尾的**铅笔按钮**编辑。**右键节点**打开节点操作菜单，详见[对话节点与侧栏](/zh/guides/conversations#节点右键菜单)。

### 问答节点的语义图标

较长的回答完成后，ThoughtDAG 会在后台为当前问答生成一句地图摘要，并判断这一轮在思考过程中起到的作用。缩小画布时，节点会显示相应图标：

| 图标 | 含义 |
| --- | --- |
| **✦** | 洞见：得到或确认了一项认识 |
| **✕** | 排除：否定了一个假设或选项 |
| **⚖** | 决策：在多个选项中作出选择 |
| **↩** | 转向：重新界定问题或改变方向 |
| **?** | 未解：留下一个尚未回答的问题 |

这些图标**不是新的节点类型**，只是帮助浏览思路的语义标记；它们不会改变节点内容，也不会自动改变模型上下文。较短或尚未分类的问答节点在最远视图中显示为普通圆点。

评审节点和凝练节点还会使用各自的专用标记，具体操作分别见[版本、陈旧与重放](/zh/guides/versions-replay)和[合并、高亮与凝练](/zh/guides/organize)。

![中文节点右键菜单](/screenshots/interface-overview/zh/node-context-menu-zh.png)

## 4. 连线

- **紫色实线**：主要对话路径，传递完整上游上下文；
- **橙色实线**：从所选文字建立的探索分支，仍属于上下文结构；
- **紫色虚线**：摘要引用，只把指定节点的问答和上游问题线索带入；
- **红色虚线**：随动评审关系。

选中可转换的连线后，会显示预计 token 和转换按钮；也可以删除该连线。详细说明见[控制上下文](/zh/guides/context-control)。

## 5. 浮动侧栏

[浮动侧栏](/zh/guides/conversations#浮动侧栏的功能区)显示完整问题与回答、当前版本、上下文树、高亮、引用和继续追问的输入框。它覆盖在画布上方，不会改变节点的实际位置。

![中文对话节点与浮动侧栏](/screenshots/interface-overview/zh/node-panel-zh-annotated.png)

红色说明框用于定位当前节点、问题、回答、上下文区域和追问入口；它们不属于应用界面。

## 6. 追问输入框与上下文预览

浮动侧栏底部的输入框用于从当前问答节点继续。输入框上方会显示一行摘要，例如 **“将发送约 1109 tok · 8 条消息”**。它不是独立的工具栏按钮；点击这行摘要，才会展开[下一次追问的上下文预览](/zh/guides/context-control#检查下一次请求)。

![中文追问输入框与将发送摘要](/screenshots/interface-overview/zh/followup-context-preview-zh.png)

展开后可以检查材料、显式引用、对话轮次、消息数和估算 token。这个入口只属于节点侧栏中的继续追问；在空白画布上开始第一个问题时，使用的是主输入框，不会显示这行摘要。
