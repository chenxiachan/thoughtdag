# 功能状态

| 能力 | 状态 | 文档边界 |
|---|---|---|
| 图式对话与上下文连线 | 当前功能 | 产品核心行为 |
| 分支、合并、剪枝、重算与重放 | 当前功能 | 使用受控的上下文前后对比演示 |
| PDF 阅读与内容摘取 | 当前功能 | 保留来源和页码 |
| 本地存储、备份、导出与分享 | 当前功能 | 不承诺未经验证的全部跨版本兼容性 |
| 受支持本地会话的 Agent 对话地图 | 当前桌面功能 | 已适配 Codex 与 Claude Code；runner 格式可能变化 |
| 增量会话镜像与 tool result 附件 | 当前桌面功能 | 画布修改不写回来源；适配范围可能扩展 |
| Context Bundle v0 | 实验性提案 | 可运行 fixture 不等于兼容标准已冻结 |
| 自动多 Agent 调度 | 不属于当前承诺 | 不应暗示对话地图会调度 Agent |
| 写回原始 Agent session | 不支持 | 镜像与来源日志保持分离 |

“已经实现”“实验能力”和“设计提案”是不同结论。能在本地成功演示一次，不代表已经稳定兼容所有外部工具。
