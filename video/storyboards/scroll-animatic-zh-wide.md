# ThoughtDAG — 中文横版故事短片

规格：1920×1080，30 fps，30.5 秒。

这版与英文版使用完全相同的叙事因果链：从一篇论文、一个问题开始，
问题逐渐增加，聊天记录越来越长，直到使用者看不清下一次回答会带上
哪些上下文。随后，同一组内容从聊天记录中展开为可编辑的图。

| 时间 | 故事节点 | 屏幕主文案 | 画面因果 |
| --- | --- | --- | --- |
| 0:00–0:02.5 | 起点 | 一篇论文 / 一个问题 | 从论文中的一段高亮内容开始提问。 |
| 0:02.5–0:06.5 | 累积 | 然后，问题 / 越来越多 | 证据、图片区域、反例与意外想法进入同一段对话。 |
| 0:06.5–0:10 | 冲突 | 下一次回答 / AI 究竟会记得什么？ | 对话继续变长，而真正送入下一次请求的上下文被藏在聊天记录里。 |
| 0:10–0:12.5 | 停顿 | 可我已经 / 看不见上下文了 | 动画暂缓，拥挤的对话被留在背景。 |
| 0:12.5–0:16 | 转折 | 所以，我把对话 / 摊开成一张图 | 同一组对话卡片移动、展开并连接成图。 |
| 0:16–0:22 | 行动 | 想法可以留下 / 上下文由我决定 | 偏离的想法留在画布上，但连线被切断；相关路径合并进入下一次回答。 |
| 0:22–0:25.5 | 回报 | 现在，我能决定 / AI 下一次记得什么 | 回答只根据被选中的三条路径重新生成。 |
| 0:25.5–0:30.5 | 产品真相 | 连线，就是上下文 | 文案收束到 ThoughtDAG 标志与放大的 GitHub 搜索提示。 |
