# 键盘快捷键

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 撤销 | `Cmd+Z` | `Ctrl+Z` |
| 重做 | `Cmd+Shift+Z` | `Ctrl+Shift+Z` |
| 搜索画布 | `Cmd+F` | `Ctrl+F` |
| 折叠或展开所选节点 | `Space` | `Space` |
| 重新生成所选节点 | `R` | `R` |
| 沿连接节点移动 | 方向键 | 方向键 |
| 退出当前层级 | `Esc` | `Esc` |
| 删除所选连线或多节点选区 | `Delete` / `Backspace` | `Delete` / `Backspace` |

方向键只沿结构连线移动。删除键只作用于所选连线，或包含两个以上节点的选区；删除单个节点请使用节点操作。输入框处于编辑状态时，普通文字编辑行为优先。
